    PAYOUT AGENT · READ-ONLY CHECK
    
              
    Check the live finalized contract state, current recipient, contribution count, deadline, and protection reserve. This does not release a payout or submit a blockchain transaction.
    
              
    
                
                
              
    
              
    
              
    PROTECTED PUBLIC CIRCLE · FINAL DISTRIBUTION
    
              
    Read the finalized testnet contract and assess whether the accumulated public-circle pool is blocked, ready, pending, retryable, or complete. This control is strictly read-only: it never starts, retries, or submits a transfer.
    
              
    
                
                
              
    
              
    
              
    PUBLIC DISTRIBUTION EXECUTION · TWO-MEMBER AUTHORIZATION
    
              
    Prepare the verified plan while signed in as one active member. A different active member must sign in and authorize the exact plan. Only then can the treasury CLI start one transfer at a time. Check status between transfers; never retry an uncertain transaction.
    
              
    
                
                
              
    
              
    
              
    
                
                
                
              
    
              
    
                
                
                
              
    
              
    
                
                
                
              
    
              
    
                
                
              
    
              
    
              
    When the live contract is ready, you can create a durable payout plan for review. This still does not authorize a payout, sign, or submit a blockchain transaction.
    
              
              
    
              
    
                
                
              
    
              
    
              
    SECOND-OPERATOR APPROVAL · LEDGER ONLY
    
              
    Sign in with a different active circle member than the account that prepared the plan. This records independent approval only; it does not sign or submit a blockchain transaction.
    
              
    
                
                
                
              
    
              
    
              
    LOCAL CLI-SIGNED PAYOUT · TESTNET ONLY
    
              
    This is the only app control that can submit the payout. It rechecks the authorized plan, deployed code hash, schedule parity, and live readiness on the server, then uses the existing NEAR CLI keychain only if its public key matches a finalized FullAccess key for the exact contract. Review the contract, round, recipient, amount, and testnet in the confirmation dialog. A successful transaction submission still needs a separate payout-completion check.

This form does not send a transaction. Never paste a private key or seed phrase.
